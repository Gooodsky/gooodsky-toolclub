# Delivery Checklist — Website Clone & Redesign

Use this checklist before marking any order as delivered. Check off each item as it is completed.

---

## Basic Package — $150 (Single-Page Clone)

### Included
- [ ] 1 landing page cloned and rebuilt in Next.js 15+ + Tailwind CSS 4
- [ ] Desktop + Mobile responsive layout
- [ ] Basic SEO meta tags (title, description)
- [ ] Standard performance optimization
- [ ] Clean, organized source code
- [ ] 1 round of revisions
- [ ] Delivery within 3 days

### Not Included
- Tablet breakpoint optimization
- Open Graph / Twitter Card metadata
- Image optimization or code splitting
- Animations or transitions
- Contact forms
- API integrations
- Vercel deployment
- Post-delivery support
