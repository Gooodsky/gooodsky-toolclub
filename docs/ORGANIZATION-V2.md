制定：2026-06-05
目标：一人公司全自动运行，实现盈利

## 核心架构 — 一相六卿制

```
👑 皇帝（老板）— 定方向、审大策、收成果
  │
  └── 🏛 丞相（CEO·Claude Code）— 统全局、决万事、奏圣听
        │
        ├── ⚔️ 太尉（COO·Agency v1.6.3）— 督军务、掌流水、核质量
        │     └── 调度六部 Agent 执行任务
        │
        ├── 🛡️ 征西将军（CTO·OpenClaw 2026.6.1）— 破反爬、隐行踪、取情报
        │     └── 先锋：CloakBrowser
        │
        ├── ⚙️ 大匠卿（CTO·n8n v2.23.2）— 建流水、通关节、自运转
        │     └── 传令使：BullMQ
        │
        ├── 🤝 鸿胪卿（CrewAI v1.14.6）— 协百官、调众议、决疑难
        │     └── 文书：Hermes | 谋士：AutoGen
        │
        └── 六部尚书（虚拟Agent·CEO动态生成）
              ├── 吏部（人事）— 招聘调配
              ├── 户部（财政）— 收钱算账
              ├── 礼部（外交）— 客服营销
              ├── 兵部（研发）— 写代码
              ├── 工部（建设）— 部署运维
              └── 刑部（风控）— 质量审查
```

## 赚钱流水线

```
客户访问 toolclub.net
  → 下单（Stripe）
  → n8n 触发自动流程
  → Agency 分配任务给六部
  → 部门执行交付
  → CrewAI 复杂任务协同
  → Hermes 出财务报告
  → CEO 向老板汇报
```
