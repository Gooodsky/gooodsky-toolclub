## 区块顺序 (自上而下)

### 1. Header / Nav (sticky top)
- **交互模型:** scroll-driven (滚动时可能缩小/阴影变化) + hover-driven (下拉菜单)
- **内容:** Logo + 股票代码 + 导航菜单(产品与服务/行业解决方案/公司/AI研究院) + 电话 + 登录 + 立即咨询
- **类型:** sticky, 全局

### 2. Hero Banner
- **交互模型:** static (无交互)
- **内容:** "视频魔方-轻松玩转 企业短视频营销" + 描述 + CTA按钮 + 右侧装饰图
- **背景:** banner_bg.png (蓝色渐变)
- **类型:** 普通流内容

### 3. 五大痛点 Carousel
- **交互模型:** click-driven (左右箭头 + Swiper轮播)
- **内容:** 标题 + 5张痛点卡片(账号定位困难/养号启动困难/运营经验缺乏/内容创作乏力/流量无法破圈) + 左右箭头
- **类型:** 普通流内容

### 4. 六步运营方案
- **交互模型:** static
- **内容:** 标题 + 副标题 + 6步流程图(带编号图标) + "领取专属解决方案" 链接
- **背景:** bg_02.png
- **类型:** 普通流内容

### 5. 短视频营销获客系统
- **交互模型:** static (4列卡片)
- **内容:** 标题 + 描述 + 4张功能卡片(视频原创引擎/视频曝光/营销裂变/客户转化)

### 6. AI赋能短视频营销
- **交互模型:** click-driven (轮播 + 圆点指示器)

### 8. CTA / Contact Banner
- **交互模型:** static
